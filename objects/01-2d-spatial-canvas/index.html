A computational installation about family memory, paper, wind, flowers, distance, and return. This folder contains one static 2D canvas and two dynamic 2D canvases.

2D Canvas 01 · Static Archive Board

The Letter Archive

A tactile memory archive board built as a static 2D composition: an aged Thailand map anchors a family photo, a handwritten letter, a ticket, and a diary page, all connected by red thread and a narrative timeline.

2D Canvas 02 · Dynamic

Wishing Tree

Red flowers bloom on a tree. Hanging letters swing with wind. Move the mouse to change the wind.

2D Canvas 03 · Dynamic

Red Cotton Flower

A large red flower carries floating letter papers against a muted teal paper background.

2D Design Statement

These canvases translate memory into layered images. In The Letter Archive, the composition behaves like a quiet evidence board: Thailand becomes a paper map, Bangkok becomes a pin, and family memory is distributed across a photograph, a letter, a train ticket, and a diary fragment. Red thread links each artifact to the map and the bottom timeline, turning biography into a readable spatial narrative. The two dynamic canvases extend that language into wind, bloom, and suspended letters.

Some letters crossed the sea.
Some never arrived.
