# Letters Across the Sea — 2D Spatial Canvas

Standalone GitHub Pages-ready folder containing the three p5.js canvases:

- The Letter Archive — static
- Wishing Tree — dynamic, mouse-controlled wind
- Red Cotton Flower — dynamic bloom and hanging letters

## Structure

- `index.html`
- `style.css`
- `js/archive.js`
- `js/wishingTree.js`
- `js/cottonFlower.js`

Open `index.html` locally, or upload this folder as a static website.

Author: Yizhang Mu (he/him), Columbia University GSAPP


## Update

The static Letter Archive panel was refined as a curated image-based archival board with a Thailand map, family photo, letter, ticket, diary page, red thread, and a narrative timeline.


## The Letter Archive

This static 2D canvas is a memory archive board organized around an aged map of Thailand. A family photograph, a handwritten letter, a travel ticket, and a diary page are connected by red thread to Bangkok, while a bottom timeline ties years to artifacts so the composition reads as a spatial narrative rather than a decorative collage.
