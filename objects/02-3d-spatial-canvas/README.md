# Letters Across the Sea — 3D Spatial Canvas

Standalone GitHub Pages-ready folder containing the three Three.js canvases:

- Invisible Routes — paper constellation and cursor gravity
- Sea of Letters — animated paper ocean
- Archive Lantern — orbiting paper fragments and warm light

## Structure

- `index.html`
- `style.css`
- `js/routes3d.js`
- `js/ocean3d.js`
- `js/lantern3d.js`

Open `index.html` locally, or upload this folder as a static website.
