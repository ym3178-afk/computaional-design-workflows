00 / OVERVIEW

Seven assignments, one study of invisible structures.

Each exercise remains an independent digital object, while the website connects them through one visual language. Paper, maps, timelines, networks, polls, and conversational guidance become different methods for making hidden structures perceptible.

01 / OBJECT INDEX

Seven ways to structure information and experience.

01

2D SPATIAL CANVAS · P5.JS

Letters Across the Sea

Attempt. Translate family memory, migration, paper, flowers, and suspended letters into layered 2D compositions, beginning with a static memory archive board.

Interaction and references. A static archive board with a Thailand map, family photograph, handwritten letter, ticket, diary page, red thread, plus two p5.js dynamic canvases shaped by wind and bloom.

02

3D SPATIAL CANVAS · THREE.JS

Constellation, Ocean, Lantern

Attempt. Turn paper fragments into navigable spatial fields that behave like routes, waves, and orbiting memory.

Interaction and references. OrbitControls, cursor gravity, animated waves, auto-rotation, fog, warm light, constellations, the sea, and lantern rituals.

Open object ↗
03

TEMPORAL STRUCTURE · D3.JS

A City Learns to Use Less

Attempt. Compare forty-six years of population, total water consumption, and per-capita demand to reveal how urban growth can separate from resource use.

Dataset and interaction. NYC Open Data / DEP annual water records, an external CSV, metric switching, hover inspection, animated axes, year-over-year bars, and a normalized 1979 baseline comparison.

Open object ↗
04

RELATIONAL STRUCTURE · D3.JS

The Invisible Boss

Attempt. Represent algorithmic management as a socio-technical network instead of a single visible authority.

Data and interaction. 24 nodes, 48 relationships, six edge types, filters, zoom, pan, draggable nodes, persistent selection, and relationship tracing.

Open object ↗
05

GEOSPATIAL STRUCTURE · MAPBOX GL JS

The Last 800 Meters

Attempt. Examine how restaurant supply, distance, cuisine concentration, and Broadway–Amsterdam corridors structure potential food access around Columbia.

Datasets and interaction. NYC DOHMH records, fallback GeoJSON, cuisine and distance filters, 400/800/1,200 m bands, access points, corridor proxies, popups, and presentation mode.

Open object ↗
06

ENGAGEMENT COMPONENT · FIREBASE

Columbia Study Space Poll

Attempt. Turn a small act of participation into live, aggregated evidence about preferred study spaces.

Data and ethics. Firebase Realtime Database, six categories, live counts and percentages, one stored choice per browser, change-vote logic, and explicit limits around privacy and representativeness.

Open object ↗
07

AGENT · CONTEXT RETRIEVAL

Context Guide Agent

Attempt. Build a narrow conversational guide that helps visitors navigate the final archive using explicit project context.

Interaction and method. Suggested prompts, project-specific keyword retrieval, transparent local processing, direct links, and no private API key embedded in the browser.

02 / AESTHETIC PRIORITIES

The visual system is explicit and ordered.

  1. 01
    Archival atmosphere

    Warm ivory, soft sage, stone, charcoal, and one muted clay accent create a calm, understated archive.

  2. 02
    Legibility

    Instrument Serif headings and Inter body text establish a restrained, consistent hierarchy across all seven objects.

  3. 03
    Cross-object coherence

    One muted palette, consistent numbering, margins, borders, object statements, and navigation make seven assignments read as one project.

  4. 04
    Interaction with restraint

    Soft contrast and minimal controls keep attention on the objects, interactions, and datasets.
