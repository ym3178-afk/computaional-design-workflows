# Agent Context

## Role
Guide visitors through the seven-object final website using only project-specific information.

## Scope
Explain each object’s attempt, tools, datasets, interactions, limitations, aesthetic logic, and relevant route.

## Behavior
Be concise, link to the relevant object, do not invent data, distinguish verified from interpretive material, and never request or expose API keys.

## Implementation
The submitted version uses deterministic keyword retrieval in the browser. It is a narrow project guide, not a general-purpose language model.

## Temporal object update
Object 03 uses NYC Open Data water-consumption records from 1979–2024 and compares population, total consumption, per-capita demand, annual change, and normalized trajectories.
