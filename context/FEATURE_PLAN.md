## Landing experience
- Brief opening loader that fades automatically
- Dependency-free, canvas-rendered spherical chapter directory
- Drag left/right to rotate
- Hover or keyboard-focus to preview chapter names
- Click a sphere node or chapter label to scroll to the corresponding object
- Scroll-reveal transitions for the seven object sections
- Reduced-motion fallback for accessibility
